# Butwal Skills Training Institute Online Admission

This solution is the Butwal Skills Training Institute online admission application. Open and run `AdmissionWeb/AdmissionWeb.csproj` for the student website and staff dashboard. The supplied Windows Forms car-rental source is retained only in `Original_Project_Backup/` and is not part of the admission solution or workflow.

## Quick start

1. Open `ButwalAdmission.sln` in Visual Studio 2026 or newer, or use the .NET 10 SDK.
2. Restore packages and run the `AdmissionWeb` project.
3. Follow `AdmissionWeb/README.md` to create the first administrator.

The full student, database, admin and hosting guide is in [AdmissionWeb/README.md](AdmissionWeb/README.md). No public website has been deployed.

The supplied poster's logo has been cropped into `AdmissionWeb/wwwroot/assets/butwal-skills-logo.png` and is displayed on the website. Course names, listed curriculum, location, phone number, promotional text and advertised fees use the poster. No payment QR, bank details, eSewa credentials, offer dates or testimonials have been invented. The Diploma offer remains flagged for institute confirmation as directed by the poster.
